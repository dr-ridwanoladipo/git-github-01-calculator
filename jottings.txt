# Git & GitHub Evolution Project

A simple calculator project built to demonstrate how a software project evolves with Git and GitHub.

## What You'll Learn

- Creating a Git repository
- Making meaningful commits
- Tracking project history
- Branching and merging
- Resolving conflicts
- Using GitHub professionally

Each commit represents a new stage in the project's evolution, making it easy to understand Git workflows from beginner to advanced.
